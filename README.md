# ⏰ Alarm Samy - منبه سامي الذكي للآيفون (iOS)

تطبيق منبه وتذكيرات عربي بالكامل بتصميم فخم باللون الأزرق الملكي والأبيض + وضع ليلي أزرق نيون (**Dark Royal Blue Mode**)، مصمم خصيصاً للآيفون وجاهز لاستخراج ملف **`Alarm_Samy.ipa`** مباشرة عبر **Codemagic**.

---

## ✨ المميزات الرئيسية في Alarm Samy

1. **واجهة عربية بالكامل (RTL) مع أنيميشن متحرك**:
   - رادار وساعة حية ثلاثية الأبعاد بنبضات ضوئية متحركة.
   - وضعان للألوان: **دارك مود أزرق ملكي (Dark Blue Neon)** و **أبيض في أزرق (Light Blue & Crisp White)**.
2. **تحديات الاستيقاظ الذكية (عشان تتأكد إنك صحيت فعلاً 🧠)**:
   - **معادلات حسابية ذكية**: ٤ مستويات صعوبة (سهل، متوسط، صعب، خارق 🔥) مع تحديد عدد الأسئلة من ١ إلى ٥.
   - **شحن طاقة الاستيقاظ السريع ⚡**: عداد طاقة يتناقص تلقائياً ويتطلب ضغطاً متتالياً سريعاً للوصول إلى 100%.
   - **كتابة العبارة الصباحية التحفيزية ⌨️**: كتابة جملة صباحية تحفيزية بدقة لإغلاق المنبه.
   - **تحدي الذاكرة المضيئة (Pro 👑)**: حفظ مواقع المربعات الزرقاء المضيئة والضغط عليها بنفس الترتيب.
   - **ترتيب الأرقام التصاعدي السريع (Pro 👑)**: النقر على الأرقام المبعثرة من الأصغر للأكبر.
   - **تحدي التركيز اللوني المخادع Stroop (Pro 👑)**: اختيار لون الحبر الفعلي للكلمة وليس النص المكتوب.
3. **حاسبة دورات النوم وقيلولة الطاقة السريعة**:
   - أزرار قيلولة فورية بضغطة واحدة (+15 د، +20 د، +30 د، +45 د، +60 د).
   - حاسبة دورات النوم (٩٠ دقيقة للدورة) لاقتراح أفضل وقت للاستيقاظ بدون خمول.
4. **استوديو النغمات وإضافة نغمات مخصصة 🎵**:
   - نغمات مدمجة مولدة صوتياً بدقة عالية (نبض الفجر الأزرق، أجراس الكريستال، رادار الآيفون، إنذار الصاعقة للنوم الثقيل 🚨، سيمفونية القمة الملكية 👑).
   - **إضافة نغمة من جهازك**: استيراد أي ملف صوتي (`MP3`, `WAV`, `M4A`) من جهازك.
   - **استوديو تأليف الألحان**: تأليف نغمة منبه خاصة بك من النوتات الموسيقية والتحكم في سرعة الإيقاع.
5. **التذكيرات والمهام اليومية الذكية 📝**:
   - تقسيم التذكيرات حسب الفئة (عمل، دراسة، صحة وأدوية، رياضة، شخصي) مع شارة الأولوية القصوى 🔥.
6. **النسخة المجانية والنسخة الـ Pro 👑**:
   - شاشة اشتراكات متكاملة توضح الفرق بين النسخة المجانية وباقات **Alarm Samy Pro** (تجربة مجانية ٧ أيام، شهرية، سنوية، ومدى الحياة) مع إمكانية التفعيل الفوري والتبديل بين النسختين للتجربة.

## 🚀 خطوات الرفع على GitHub وبناء ملف `Alarm_Samy.ipa` على Codemagic

### ١. رفع المشروع على GitHub
افتح التيرمينال داخل مجلد المشروع ونفذ الأوامر التالية:
```bash
git init
git add .
git commit -m "Initial commit: Alarm Samy full Arabic iOS app"
git branch -M main
git remote add origin https://github.com/<USERNAME>/<REPO_NAME>.git
git push -u origin main
```

### ٢. بناء ملف الـ IPA على Codemagic
1. سجل الدخول في موقع [Codemagic.io](https://codemagic.io) بحساب GitHub الخاص بك.
2. اضغط على **Add application** واختر مستودع **Alarm Samy** ونوع المشروع **Flutter App (via codemagic.yaml)**.
3. سيقرأ Codemagic ملف [`codemagic.yaml`](codemagic.yaml) تلقائياً.
4. اضغط **Start new build** واختر الـ Workflow المسمى:
   `Alarm Samy - Build iOS IPA (Unsigned for Sideloadly / AltStore)`.
5. بعد انتهاء البناء (حوالي ٥ إلى ٨ دقائق)، ستجد ملف **`Alarm_Samy.ipa`** جاهزاً للتحميل في قسم **Artifacts** لتثبيته على الآيفون عبر **Sideloadly** أو **AltStore** أو **SideStore** أو **Scarlet** أو **TrollStore**!
